Marine Automation & Control Systems

Engine-room automation is not a box — it is the chain from the sensor to the engineer's screen. We take on that entire chain: field instrumentation, cabling, I/O, control logic, HMI and documentation, for main and auxiliary systems on ships and yachts.

The work is done by an engineer who has stood where the user stands: 15+ years as an Electro-Technical Officer in the merchant marine, on gas carriers. That changes the design. Logic is written to be diagnosable at three in the morning, not merely to pass FAT.

Scope of work

  • Control-logic design for auxiliary machinery — pumps, compressors, separators, boilers, condensers
  • Installation and upgrade of engine-room control panels
  • Field instrumentation: pressure, temperature, level and flow — 4–20 mA, Pt100, thermocouples
  • PLC programming and HMI screen design in the crew's working language
  • Integration of standalone third-party systems into a single monitoring picture
  • Interlock, permissive and safety-shutdown design
  • Loop checking, functional testing and witnessed commissioning
  • Updated as-built drawings and I/O lists on handover

Typical symptoms & failures

  • The system drops sensors, or shows values that disagree with the local gauges
  • Repeated shutdowns with no obvious cause and a gap in the alarm log
  • Machinery run in manual indefinitely because nobody trusts the automation
  • HMI screens that no longer match the installation in front of you
  • Drawings two retrofits behind reality

What you receive

  • A functional description agreed before a line of code is written
  • PLC/HMI program backup handed to the owner — not locked away
  • Signed loop-check and functional-test protocol
  • Updated as-built drawings and I/O list
  • Short crew handover on the new functionality

Equipment & protocols

  • PLC: Siemens S7 / LOGO!, Schneider, Omron, Mitsubishi
  • Industrial HMIs and panel PCs
  • Protocols: Modbus RTU / TCP, CANopen, J1939, Profibus, Ethernet/IP
  • Signal conditioning, isolators, intrinsically-safe barriers where required
  • Work carried out to IEC 60092 and the vessel's class-society requirements

Frequently asked questions

Can you work on another manufacturer's system?

Yes. Most of our work is on installations built by someone who is no longer around. We start by mapping the existing logic and wiring before proposing anything.

Do you hand over the PLC source code?

Yes — to the owner or the technical department. A vessel should not be hostage to one supplier for a single parameter change.

How long does an automation upgrade take?

It depends on scope and whether the vessel is trading. A targeted control-panel upgrade fits inside one port stay; a full engine-room retrofit is planned around docking.

Need an engineer onboard?

Send us the fault, the vessel type and the equipment involved. You get a concrete intervention plan back — not a generic quote.
